# Reference management

Store citation **metadata and bibliographies** here, preferably exported from Zotero in BibTeX or CSL JSON. Do not commit copyrighted article PDFs unless redistribution is permitted.

Suggested workflow:

1. Create a Zotero collection for the thesis.
2. Tag papers by themes: price-volume, volatility, efficiency, liquidity, data quality.
3. Export verified metadata to `references.bib` (or CSL JSON).
4. Keep the literature reading matrix in sync with the bibliography.
5. Verify titles, DOI, publication venue, and page ranges before submission.

The provisional bibliography is listed in `literature-review/01-foundations-and-crypto-markets.md`. It has not yet been checked against the user's Zotero library.
