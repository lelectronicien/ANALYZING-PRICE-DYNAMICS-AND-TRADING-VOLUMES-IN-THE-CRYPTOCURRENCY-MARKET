# Confirmed empirical protocol: 2018–2025

**Confirmed by researcher:** 2018-01-01 through 2025-12-31 inclusive; daily UTC frequency. **Exclusive API end:** 2026-01-01.

- **Expected daily candles:** 2,922 per continuously traded symbol (8 calendar years; leap days 2020 and 2024).
- **Core assets:** BTC and ETH, candidate spot pairs BTCUSDT and ETHUSDT.
- **Primary outcomes:** daily absolute log returns and volatility proxies; directional returns secondary.
- **Primary volume metric:** log(1 + USDT quote turnover) at a single exchange; base-asset volume as sensitivity analysis when implemented.
- **Main descriptive analysis:** contemporaneous volume–absolute-return association with HAC standard errors.
- **Predictive test:** expanding-window one-day-ahead absolute-return forecasting, autoregressive baseline versus volume-augmented regression.
- **Validation:** compare MAE and RMSE across the same forecast dates; inspect loss differences and uncertainty before claiming an improvement.
- **Robustness:** squared-return alternative, volume log changes, 2018–2021 versus 2022–2025 subsamples, alternative lag specifications and provider cross-checks (latter two planned).
- **No leakage:** features at t predict t+1, training is chronological, and no future target enters fitting.
- **Limitations:** unadjusted multiple comparisons, exchange-specific reported volume, structural breaks, no causal identification.

## Data acquisition gate

Before inference, verify 2,922 unique, valid, UTC-midnight candles for each asset, document missing/duplicate bars and zero volumes, check provenance and license, and cross-check sample bars against an independent authorized source. The code does not substitute for actually performing this audit.

Implemented modules: `src/coverage.py`, `src/walk_forward.py`, `src/robustness.py`. These are first-pass research scripts and are not yet empirically validated. Confirmatory specifications and final significance thresholds require supervisor approval before results are inspected.
