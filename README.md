# Analyzing Price Dynamics and Trading Volumes in the Cryptocurrency Market

Master's thesis research and development repository.

## Research overview

This project investigates the relationship between cryptocurrency market price dynamics and trading volumes. It serves as a reproducible workspace for literature review, research design, data preparation, empirical analysis, experiments, visualizations, and thesis writing.

The precise hypotheses, study period, data sources, cryptocurrencies, and statistical methods will be documented as the thesis develops.

## Repository structure

| Directory | Purpose |
| --- | --- |
| `literature-review/` | Research papers, structured literature notes, synthesis |
| `references/` | Citation metadata, Zotero exports, bibliography files |
| `thesis/chapters/` | Chapter manuscripts and source files |
| `thesis/drafts/` | Working drafts and revisions |
| `methodology/` | Research questions, methodology, variable definitions |
| `data/` | Data dictionaries, acquisition notes and non-restricted datasets |
| `src/` | Reusable scripts for ingestion, cleaning, analysis and modeling |
| `experiments/` | Experiment settings, notebooks, exploratory work |
| `results/` | Tables, reproducibility notes and model outputs |
| `figures/` | Visualizations for the thesis and publications |
| `presentations/` | Proposal, progress and defense slides |
| `reports/` | Progress reports and research documentation |

## Research workflow

1. Define and refine research objectives and hypotheses in `methodology/`.
2. Record related work in `literature-review/` and manage citations through `references/`.
3. Document data provenance, quality checks and permitted data reuse in `data/`.
4. Implement reproducible analyses in `src/` and track experiments in `experiments/`.
5. Archive results and figures, then incorporate verified findings into `thesis/`.

## Reproducibility and responsible sharing

- Record exchange, trading pair, timeframe, market timezone, retrieval date and any transformations for each dataset.
- Prefer scripts or instructions for obtaining data over committing large raw market data.
- Do not commit API keys, passwords, non-public datasets, private documents, or copyrighted articles without redistribution rights.
- Document package dependencies and execution instructions as the analysis code is added.
